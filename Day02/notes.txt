## 1. Data Types in SQL

### Syntax

```sql
CREATE TABLE table_name (
    column1 INT,
    column2 VARCHAR(50),
    column3 DATE,
    column4 DECIMAL(10,2)
);
```

### Explanation

* `CREATE TABLE` → Creates a new table
* `column1 INT` → Stores integer values
* `VARCHAR(50)` → Stores text up to 50 characters
* `DATE` → Stores date values (YYYY-MM-DD)
* `DECIMAL(10,2)` → Stores numbers with precision (total 10 digits, 2 after decimal)

### Example

```sql
CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    dob DATE,
    marks DECIMAL(5,2)
);
```

### Output Explanation

A table named `students` is created with 4 columns of different data types.

---

## 2. INSERT Statement

### Syntax

```sql
INSERT INTO table_name (column1, column2, column3)
VALUES (value1, value2, value3);
```

### Explanation

* `INSERT INTO` → Adds new data into a table
* `(column1, column2)` → Specifies columns to insert data into
* `VALUES` → Actual data to be inserted

### Example

```sql
INSERT INTO students (id, name, dob, marks)
VALUES (1, 'Rahul', '2000-05-10', 85.50);
```

### Output Explanation

A new row is added to the `students` table.

---

## 3. SELECT Statement

### Syntax

```sql
SELECT column1, column2
FROM table_name;
```

### Explanation

* `SELECT` → Retrieves data from a table
* `column1, column2` → Specifies which columns to fetch
* `FROM` → Specifies the table

### Example

```sql
SELECT id, name
FROM students;
```

### Output Explanation

Displays `id` and `name` of all students.

---

## 4. DISTINCT Keyword

### Syntax

```sql
SELECT DISTINCT column_name
FROM table_name;
```

### Explanation

* `DISTINCT` → Removes duplicate values
* Returns only unique values from the column

### Example

```sql
SELECT DISTINCT marks
FROM students;
```

### Output Explanation

Shows unique marks without repetition.

---

## 5. WHERE Clause

### Syntax

```sql
SELECT column1, column2
FROM table_name
WHERE condition;
```

### Explanation

* `WHERE` → Filters rows based on a condition
* `condition` → Can use operators like `=`, `>`, `<`, `AND`, `OR`

### Example

```sql
SELECT name, marks
FROM students
WHERE marks > 80;
```

### Output Explanation

Returns only students with marks greater than 80.

---

## 6. Constraints

### a) NOT NULL

#### Syntax

```sql
CREATE TABLE table_name (
    column_name datatype NOT NULL
);
```

#### Explanation

* `NOT NULL` → Ensures the column cannot have empty (NULL) values

#### Example

```sql
CREATE TABLE students (
    id INT NOT NULL,
    name VARCHAR(50) NOT NULL
);
```

### Output Explanation

Both `id` and `name` must always have values.

---

### b) UNIQUE

#### Syntax

```sql
CREATE TABLE table_name (
    column_name datatype UNIQUE
);
```

#### Explanation

* `UNIQUE` → Ensures all values in the column are different

#### Example

```sql
CREATE TABLE users (
    email VARCHAR(100) UNIQUE
);
```

### Output Explanation

No two users can have the same email.

---

### c) PRIMARY KEY

#### Syntax

```sql
CREATE TABLE table_name (
    column_name datatype PRIMARY KEY
);
```

### Explanation

* `PRIMARY KEY` → Uniquely identifies each row
* Cannot have `NULL` values
* Automatically enforces uniqueness

### Example

```sql
CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(50)
);
```

### Output Explanation

Each student must have a unique `id`, and it cannot be empty.
